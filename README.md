# blis-sparse-retrieval
Bônus da trilha de RAG do BLIS: recuperação esparsa aprendida. BM25, SPLADE e a parcela léxica do BGE-M3 são o mesmo objeto matemático, e só muda de onde vem o peso do termo. Inclui max pooling, FLOPS, as três funções do M3, reordenação e ablação por tipo de consulta. Dois backends, 249 testes, nenhuma API.
